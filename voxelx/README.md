# Voxel Wave

A 3D interactive wave simulation controlled by hand gestures using MediaPipe and Three.js.

## Controls

- **Pinch (Thumb + Index)**: Control the Wave Amplitude.
- **Wrist Height**: Control the Wave Frequency.
- **Hand Flip**: Change the Color Palette.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open the URL shown in the terminal (usually `http://localhost:5173`).
4. Allow camera access when prompted.

## Tech Stack

- **Three.js**: 3D Rendering.
- **MediaPipe Hands**: Real-time hand tracking.
- **Vite**: Build tool.
